# T012 — Admin account management

## Goal
Admin quản lý vòng đời tài khoản nhẹ và rõ.

## Work
- Table PENDING/ACTIVE/SUSPENDED.
- Create account.
- Activate/suspend/reactivate.
- Link/unlink person theo rule.
- Temporary password handling.

## Acceptance
- Admin thấy login name dạng `<phone>@`.
- Kích hoạt chỉ 1 click sau khi confirm.
- Audit account state changes.
